# Cross-functional handoff and sign-off checklist

## Investor committee

[ ] Product scope approved; [ ] founder equity and IP ownership decided; [ ] staged capital cap and return assumptions recorded; [ ] accuracy of market evidence understood; [ ] risks, legal dependencies and owners understood.

## Product/UX

[ ] Every screen has UX-ID and journey; [ ] brand design tokens and RTL/English variants; [ ] 360/390/768/1440 frames; [ ] public and secure persona nav; [ ] contest/AI/payment/provider failures designed; [ ] no deceptive religious or financial copy; [ ] prototype links reviewed.

## CTO/Engineering

[ ] DB choice and ADR; [ ] OpenAPI typed models; [ ] modular boundaries; [ ] video adapters POC; [ ] outbox/idempotency; [ ] payment ledger; [ ] teacher payroll snapshots; [ ] AI job orchestration and consent; [ ] monitoring and rollback.

## Academic & Safeguarding

[ ] All programs/rubrics approved; [ ] source/edition/rights confirmed; [ ] teacher vetting; [ ] exam item review; [ ] competition fairness/privacy; [ ] AI Qur'an accuracy evaluation; [ ] recording/consent SOP; [ ] escalation staffing.

## Finance/Legal

[ ] Terms and payment policy; [ ] registered entity/market; [ ] FX/settlement; [ ] taxes; [ ] teacher legal contracts; [ ] refund/compensation; [ ] prize classification; [ ] child privacy; [ ] cross-border vendors.

## QA/release

[ ] Traceability and tests green; [ ] object authorization and race tests; [ ] POC network results; [ ] mobile fallback; [ ] access audit; [ ] backup restore; [ ] staging data anonymous; [ ] user support readiness; [ ] release signoff.
