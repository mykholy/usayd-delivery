# أكاديمية القرآن الذكية — مواصفات التطوير النهائية v1.2 (21 نوفمبر 2026)

**تنبيه:** هذه حزمة SRS/PRD/Architecture/UX/Jira/API/QA جاهزة للبدء في بناء المنتج بشكل مرحلي، **وليست تطبيقًا منشورًا** أو Figma تم تنفيذه أو دليلًا على جاهزية Production. أي تسليم برمجي يمر باختبارات فعلية وتوقيع بشري وفق `14_RELEASE_QA/PRODUCTION_RELEASE_GATE.md`.

## أهم قرارات هذا الإصدار
- حساب طالب موحّد لكل الأعمار؛ للقاصر موافقات ومحددات بيانات لازمة بلا إجبار لوحة ولي الأمر الآن.
- إطلاق مرشح: مصر والسعودية بعد التصاريح وPSP، ثم الإمارات والكويت وقطر والبحرين وعمان، ثم الجاليات الدولية.
- لكل مستخدم: بلد الموقع/بلد الفاتورة/اللغة AR أو EN/المنطقة الزمنية IANA مستقلون؛ السعر حسب price book بالعملة المعتمدة، والخصم والتحصيل والفاتورة بحسابات دقيقة.
- الحجز UTC؛ المدرس والطالب يشاهدان بتوقيتيهما والتوقيت الصيفي مضبوط.
- اختيار مزود الاجتماعات من لوحة الإدارة ضمن سياسة معتمدة: LiveKit/VideoSDK/Daily/Zoom Video SDK/Zoom Meetings/Google Meet؛ المشترك فعال فقط للحصص الجديدة، والمميزات غير المدعومة تُعطّل بوضوح.
- أدوار مشرفين متعددة بصلاحيات محدودة جغرافيًا/أكاديميًا، وحوكمة اعتمادات المدفوعات والرقابة والخصوصية.
- مسابقات وجوائز ومراجعات واختبارات تكيفية، ومساعد AI تحت اعتماد معلم وتقييم وتجنب التحيز والتسجيل السري.
