| Context | Arabic | English | Note |
|---|---|---|---|

| Unified registration | أنشئ حساب متعلم | Create learner account | No parent-only gate |
| Minor consent pending | بانتظار موافقة ولي الأمر المطلوبة لإكمال التسجيل | Waiting for required guardian approval | Show verification steps privately |
| Next lesson | حصتك القادمة | Your next lesson | Local timezone visible |
| Join unavailable | يمكنك الدخول قبل الحصة بـ١٠ دقائق | Join opens 10 minutes before class | Configurable, example only |
| AI recommendation | اقتراح للمراجعة — لم يعتمده المعلم بعد | Suggested review — awaiting teacher approval | Never display as final |
| Memory verified | تم التثبيت وفق آخر تقييم | Verified in latest assessment | Teacher rubric source |
| Revision due | عندك مراجعة مستحقة | A revision is due | Gentle tone |
| Contest eligible | المسابقة مناسبة لمستواك | This competition matches your level | Ensure actual policy check |
| Leaderboard private | نتيجتك خاصة بك | Your result is private | Minors default |

| Certificate | شهادة إنجاز صادرة عن الأكاديمية، وليست اعتمادًا رسميًا | Academy achievement certificate, not official accreditation | Unless specifically authorized |
| Notification preferences | يمكنك إيقاف رسائل التذكير غير الضرورية | You can disable optional reminders | Quiet hours |

## Tone

Supportive, professional, encouraging and precise, not paternalistic or guilt-driven. Distinguish achieved status from prediction. Avoid AI-shaped generic religious claims and avoid unverified fatwa wording. Admin errors must state resolution and preserve action context.
