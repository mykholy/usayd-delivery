# Brand — أكاديمية أُسَيْد | Usayd Academy

- Source: Usayd Design System v1 (claude.ai artifact `1CFF8o6bniQPxouFtP9FHg`). Tokens installed on the design canvas as `project/ds/usayd/tokens.json`.
- Name: always «أُسَيْد» with full tashkeel; Latin spelling **Usayd** (not Usaid, Osaid, or “Ased”).
- Tagline: «اقرأ بصوتٍ تدنو له الملائكة».
- Mark: a canopy (ظُلّة) holding three lamps over an open mushaf. Assets: `01_design/assets/usayd-mark-*.svg`, `usayd-app-icon.svg`. Min mark size 24px; horizontal lockup min width 140px. Never recolour outside the defined tones, flip, add shadow or gradient.
- Colour ratio: ~60% parchment surface, 30% night, 10% lamp gold. Lamp gold is never text on parchment (use brass #8A5F12).
- Voice: warm, encouraging, respectful; no guilt, no streak pressure, no emoji in UI; hadith/ayat only from verified sources with citation.
- Forbidden: purple/blue gradients, neon, faces or drawings of the Sahaba, the name without tashkeel, lamp text on light backgrounds.
